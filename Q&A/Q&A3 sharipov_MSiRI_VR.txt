1. Отличие коллайдера от коллизии (в Unity / геймдеве)

• Коллайдер (Collider) — это компонент (физическая форма объекта), который прикрепляется к игровому объекту для определения его границ. Он указывает физическому движку, какую форму имеет объект (куб, сфера, сетка и т.д.) для просчета потенциальных столкновений.
• Коллизия (Collision) — это событие столкновения, физический факт того, что два коллайдера соприкоснулись в пространстве.

2. Отличие while от do while

• while (цикл с предусловием): сначала проверяет условие, а затем выполняет тело цикла. Если условие изначально ложно, код внутри цикла не выполнится ни разу.
• do while (цикл с постусловием): сначала выполняет тело цикла, а уже потом проверяет условие. Код внутри цикла гарантированно выполнится хотя бы один раз, даже если условие ложно.

3. Методы Web-запросов (HTTP-методы)

Основные методы, используемые для взаимодействия клиента с сервером:
• GET — запрашивает данные с сервера (не изменяет состояние сервера).
• POST — отправляет новые данные на сервер (обычно для создания новой записи).
• PUT / PATCH — обновляет существующие данные на сервере (PUT заменяет целиком, PATCH частично).
• DELETE — удаляет указанные данные на сервере.

4. Когда используется OnCollision и OnTrigger

• OnCollision (Событие твердого столкновения): вызывается, когда сталкиваются два твердых физических тела (у обоих есть Collider, и ни у одного не стоит галочка Is Trigger, а также присутствует Rigidbody). Объекты физически отталкиваются друг от друга.
	• Пример: мяч отскакивает от стены, персонаж врезается в коробку.
• OnTrigger (Событие триггера/зоны): вызывается, когда один из коллайдеров имеет включенную галочку Is Trigger. Объекты проходят сквозь друг друга без физического отскока, но код фиксирует пересечение границ.
	• Пример: сбор монетки, вход в зону телепорта, активация невидимой контрольной точки (checkpoint).

5. Для чего нужен интерфейс / класс Input

Класс Input в Unity (или аналогичные системы ввода в других движках) нужен для отслеживания любых действий игрока. Он считывает сигналы с различных устройств ввода и передает их в код для управления игрой.
С его помощью можно отслеживать:
• Нажатия клавиш на клавиатуре (Input.GetKey).
• Движение и клики мыши (Input.mousePosition, Input.GetMouseButton).
• Нажатия кнопок геймпада / джойстика и наклон стиков (Input.GetAxis).
• Прикосновения к экрану (тачи) на мобильных устройствах.
